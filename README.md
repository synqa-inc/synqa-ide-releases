# Synqa IDE releases

Signed and notarized macOS builds of Synqa IDE. This repository holds release files only.

## Install

1. Open the [latest release](https://github.com/synqa-inc/synqa-ide-releases/releases/latest) and download the `.dmg`.
2. Open it and drag **Synqa IDE** into Applications.

Synqa IDE checks this page for new versions and updates itself: when an update is ready it asks you to restart.

Requires macOS 13 or later on Apple silicon.
