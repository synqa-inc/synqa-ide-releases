# Security Policy

## Reporting a vulnerability

Please report security problems in Synqa IDE privately. Either:

- email **[karl@synqa.ca](mailto:karl@synqa.ca)**, or
- use **Report a vulnerability** on this repository's
  [Security tab](https://github.com/synqa-inc/synqa-ide-releases/security/advisories/new).

Do not open a public issue for a suspected vulnerability.

Include as much of the following as you can:

- the Synqa IDE version (Settings → Updates) and macOS version
- what the problem is and what an attacker could do with it
- steps or a proof of concept that reproduce it
- any logs or screenshots

Synqa is a small team, so we can't promise a fixed response time, but we read
every report and will reply as soon as we can. We will keep you updated while
we investigate, and credit you in the release notes if you would like.

## Supported versions

Only the latest release on this page receives security fixes. The app checks
here for updates and installs them for you. If you are on 1.0.0, install the
latest version by hand once so that automatic updates can reach you.

## Verifying downloads

Synqa IDE is signed by Synqa and notarized by Apple. Only download it from
[this repository's releases](https://github.com/synqa-inc/synqa-ide-releases/releases).
If macOS warns that the app is damaged or from an unidentified developer, do
not open it, and tell us at karl@synqa.ca.
